## Included frozen trap-frequency outputs

The directory

`scripts/trap_frequency_revision_results/`

contains the release-frozen outputs generated by
`scripts/trap_frequency_sensitivity_revision.py`:

- `trap_frequency_sensitivity_results.csv`
- `trap_frequency_sensitivity_comparison.csv`
- `trap_frequency_sensitivity_summary.json`
- `trap_frequency_sensitivity_table.tex`
- `trap_frequency_sensitivity_text.tex`
- `trap_frequency_sensitivity_figure.pdf`
- `trap_frequency_sensitivity_figure.png`

These files are included deliberately so that the numerical values, validation metadata, manuscript-ready tables/text, and Figure 7 output used for the revision are preserved together with the generating source code.

## Deliberately excluded

- `__pycache__` and compiled `.pyc` files
- obsolete `r_min=0.10 nm` production scripts
- duplicate figure variants and intermediate drafts
- regenerable images that are not explicitly frozen as release reference outputs
- manuscript PDFs and unrelated theory-note PDFs
- nested ZIP archives and old CPC-framework packages
- local editor and virtual-environment files
